# 📅 Gestión de Turnos TP2

Este proyecto es una aplicación web desarrollada bajo la arquitectura **Blazor Server** para la administración integral de clientes, servicios y asignación de turnos. Forma parte del Trabajo Práctico N° 2 de la carrera de Desarrollo de Software.

## 🚀 Características Principales

El sistema incluye un CRUD (Crear, Leer, Actualizar, Eliminar) completo y relacional para las siguientes entidades:

*   **👥 Clientes:** Registro y gestión de datos personales y de contacto.
*   **💼 Servicios:** Catálogo de servicios ofrecidos, incluyendo descripción y precios.
*   **🗓️ Turnos:** Asignación de turnos vinculando clientes registrados con servicios específicos, validando la entrada de datos.

## 🛠️ Tecnologías Utilizadas

*   **Framework:** .NET 8 (C#)
*   **Arquitectura:** Blazor Server (Interactive Server Render Mode)
*   **ORM:** Entity Framework Core
*   **Base de Datos:** SQL Server
*   **Diseño UI:** Bootstrap 5 (Clases nativas y componentes HTML/CSS)

## ⚙️ Requisitos Previos

Para ejecutar este proyecto en un entorno local, necesitas tener instalado:
*   [Visual Studio 2022](https://visualstudio.microsoft.com/) (con la carga de trabajo de desarrollo web y ASP.NET).
*   [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
*   SQL Server (o SQL Server Express / LocalDB).
